I run production networks at an Australian carrier, and I automate them, monitor them and test them like
software. Day to day that means BGP and OSPF on MikroTik, Cisco and Juniper, plus the systems around the
network: hypervisors, VoIP, Microsoft 365, and the monitoring that tells us when something breaks.

My GitHub is where I build the tooling I wish every NOC had: **tested, CI-validated, and runnable without
real hardware**, so anyone can clone it and see it work.
